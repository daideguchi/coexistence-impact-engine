# Pilot Evidence Template

Use this template after one real operator tries Coexistence Impact Engine.

Do not include usernames, private messages, private moderation cases, confidential community data, or API keys.

## Pilot Summary

```text
Operator role:
Community or team type:
Date:
Workflow tested:
AI participation problem:
Languages needed:
Initial reaction:
```

## Before Baseline

```text
Baseline minutes per decision or explanation:
Current policy status:
Where decisions were inconsistent:
Common user questions or disputes:
```

## Trial Evidence

```text
Decisions or explanations reviewed:
Trial minutes per decision or explanation:
Estimated time saved:
Formula: max(0, baseline minutes - trial minutes) x reviewed decisions
Policy text accepted, edited, or rejected:
Checklist items that helped:
Languages used:
```

## Public Quote

Use only if the operator agrees.

```text
Quote:
Attribution level: anonymous / role only / named
```

## Informal Early Signal

Use this only before a formal pilot. Keep it modest and honest.

```text
Who saw it:
What they reacted to:
Plain reaction:
Details shared with AI: yes / no
Measurement status: measured / aggregate-only / standard-default-only / not measured
What this suggests:
What it does not prove:
Next evidence step:
```

## Field Reality Check

Use AI here as a field-role assistant. Ask it to act as the operator who would actually use the workflow, then separate signal from proof.

```text
Field role:
Field note reviewed:
AI field reading:
Usable evidence:
Privacy limit:
Standard/default value warning:
Blocked claim:
Next measurement:
Human approval needed before publishing:
```

## What Did Not Work

```text
Confusing parts:
Missing policy cases:
Languages or wording that need improvement:
Reason the operator would not use it again:
```

## Safe Public Proof

The public proof can include:

- operator role, not private identity
- community type, not confidential community details
- counts of decisions or explanations reviewed
- estimated minutes saved with the formula
- accepted or edited policy excerpt with private details removed
- languages used
- a short approved quote

## Stoplines

- Do not claim broad impact from one pilot.
- Do not turn a casual positive reaction into formal validation.
- Do not treat standard/default values as measured impact.
- Do not pressure an operator to share private details.
- Do not let the AI field reading become the final public claim.
- Do not claim AI authorship detection.
- Do not claim final XPRIZE readiness from this template alone.
- Do not publish private data or secret credentials.
