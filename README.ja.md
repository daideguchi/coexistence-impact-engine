# 共存インパクトエンジン

[English README](README.md)

## 一言でいうと

人間とAIが一緒に働くコミュニティのために、ポリシー、多言語説明、パイロット測定を証拠パケットに変え、インパクト主張が証拠を待つ状態にするツールです。

## 誰のためのものか

AI補助の投稿や作業が混ざるコミュニティ、モデレーター、小さな組織、教育チーム、サポートチームのためのガバナンスワークフローです。

## 何が困りごとか

AIが関わる世界では、「AIか人間か」だけでは足りません。ルール、開示、説明、多言語対応、人間の承認、そして本当に役に立ったのかを測る証拠が必要になります。

## どう解決するか

- Geminiでポリシーや説明文の下書きを作ります。
- 人間の承認ゲートを明示します。
- Field Reality Checkで、現場目線の証拠と過剰主張を分けます。
- 作り手ワークフロー証拠モードで、人間のプロジェクト責任者とAIエージェントが実際に行った共同作業を第一者ワークフロー証拠として記録します。
- パイロット試行ワークスペースで前後比較を記録します。
- インパクト証拠台帳と主張の境界を出力します。

## はじめての使い方

1. 右上の `日本語` を押します。
2. 左側にコミュニティ名、困っていること、方針、説明言語を入れます。
3. `インパクトパケットを作る` を押します。
4. `中学生にもわかる説明` で、誰の何を助ける道具かを確認します。
5. `現場リアリティチェック` で、言ってよいことと言ってはいけないことを分けます。
6. `パイロット試行ワークスペース` に、実運用者が試した前後の数値を入れます。
7. `インパクトパケット出力` を、人間が確認できる提出・引き継ぎ資料として使います。

## 30秒レビュー手順

1. まず `一言でいうと` を読み、ガバナンスとインパクト測定の流れをつかみます。
2. 公開アプリを開き、`インパクトパケットを作る` を押します。
3. `Gemini証拠`、`現場リアリティチェック`、`作り手ワークフロー証拠モード`、`証拠準備の段階`、`パイロット試行ワークスペース` を見ます。
4. 最後に、第一者ワークフロー証拠はあるが、外部実運用者の前後比較が入るまで外部インパクトは主張しないと確認します。

## 画面の見方

- Geminiは下書きを助けますが、最終判断は人間が行います。
- `証拠準備の段階` は、いま何が証明済みで、何がまだ足りないかを示します。
- `現場リアリティチェック` は、反応や感想を過大評価しないための安全装置です。
- `作り手ワークフロー証拠モード` は、人間のプロジェクト責任者が方向性と承認を持ち、AIが実装・検証・記録を進めた今回の共同作業を、公開できる範囲で証拠化します。
- `パイロット試行ワークスペース` は、実データが入るまでゼロのままです。
- 外部実ユーザー、測定済みインパクト、収益、XPRIZE準備完了は、証拠が入るまで主張しません。

## 作り手ワークフロー証拠モード

この作品は、私たち自身の作業から生まれています。

今回のハッカソン作業では、人間のプロジェクト責任者が方向性、ログイン、最終承認、公開判断を持ちました。AIエージェントは、UI磨き、検証、Git commit、push、公開URL確認、README更新、正本記録を進めました。ログイン、reCAPTCHA、アカウント切替、最終提出判断、主張の境界は人間が止めて確認しました。

つまり、これは単なる例ではありません。人間のプロジェクト責任者とAI組織が実際に使った人間AI共同作業の証拠です。

ただし、これは第一者ワークフロー証拠です。外部パイロット、広い採用、売上、測定済み社会インパクトとは分けて扱います。

## 日本語対応

画面右上の `日本語` ボタンで、日本語UIに切り替えられます。AI共存は英語圏だけの話ではありません。日本人の作者として、多言語で使えること自体をプロダクト思想の一部にしています。

## 主張の境界

これはまだ最終的なXPRIZE提出証拠ではありません。Geminiの動作証拠、人間のプロジェクト責任者とAI組織による第一者ワークフロー証拠、初期フィードバックはありますが、正式な外部パイロット、測定済みインパクト、収益、広いユーザー検証はまだ主張しません。
